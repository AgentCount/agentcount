Methodology

Ledgerscope publishes facts — evidence-backed, individually checkable measurements — and flags — coordination signals with the concrete evidence attached. We do not publish a trust score: there is no observable ground truth to calibrate one against, so any weighting would be aesthetic. Consumers apply their own thresholds.

Facts we publish

Registered since
The registration event on each chain, with the transaction hash as evidence.
Endpoint liveness
{# The window and rot numbers are interpolated from the facts crate's constants — prose must not restate a threshold the code owns. #}
Raw probe counts over a {{ liveness_window_days }}-day window ("answered N of M probes"). An HTTP 402 response counts as alive — for a payable (x402) endpoint, "Payment Required" is a healthy answer.
Payable endpoint
Whether the endpoint has answered HTTP 402 — the x402 payment signal.
Metadata status
Whether the registered domain serves an agent card: resolving, rotted (unreachable for {{ rot_after_days }}+ days, with the last archived snapshot as evidence), or never resolved. Every fetch is archived — content rots; our archive doesn't.
Attestations
A raw count of on-chain feedback received ("N recorded"). In the deployed ERC-8004 model each is left by a client address, so we assert nothing about who left it or whether it's reciprocal.
Validation proofs
Present/absent counts — and "registry unavailable" where a chain has no Validation Registry (as on Base today), which is different from having zero proofs.

Flags

Shared operator
The same wallet owns multiple agent NFTs. Evidence: the address and the peer agents.
Synchronized registration
Five or more agents registered within a tight window (gaps under two minutes, window capped at one hour). Evidence: the window and the peers.

Honest limitations

  • Payment-related facts are tiered: our own test-purchase receipts (coming) are verified settlements; third-party transfers are only ever phrased as "N distinct addresses sent stablecoins" — never "N customers".
  • Flags are heuristics. Each carries its evidence precisely so you can disagree with our reading of it.
  • Probes come from identifiable infrastructure; a motivated agent could detect and special-case them. Our paid test purchases (coming) rotate identities and randomize timing to make that hard — but not impossible, and we won't pretend otherwise.
