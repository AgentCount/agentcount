# Trademark policy

**The code is Apache-2.0. The name is not.**

"AgentCount", `agentcount.ai`, and the AgentCount logo are trademarks of the
project's maintainer. The [Apache-2.0 licence](LICENSE) that covers the code
explicitly does **not** grant trademark rights (see its §6), and this document
says what that means in practice.

## You may, without asking

- Fork, modify, run and redistribute the code, commercially or otherwise, under
  Apache-2.0.
- Say your work is "based on AgentCount", "a fork of AgentCount", or
  "compatible with AgentCount" — accurate, factual references are fine and do
  not need permission.
- Cite AgentCount as the source of a published figure. Please link the run id.

## You may not, without written permission

- **Name a fork or derived service "AgentCount"**, or any name confusingly
  similar to it. Forks must rename.
- Use the AgentCount logo as your own project's mark.
- Register `agentcount` or a confusable variant as a domain, package name,
  social handle, or organisation.
- Present modified output as AgentCount's, or imply that AgentCount endorses,
  reviewed or published something it did not.

## Why a project this open bothers

The whole value of a conformance census is that a reader can tell where a
number came from. This project publishes its own retractions specifically so
that "AgentCount says X" means something checkable.

If a fork could also be called AgentCount, that guarantee breaks in exactly the
direction that matters: someone whose agent fails a check could ship a friendlier
fork under the same name, and no reader could tell the two apart. **Renaming a
fork is not a restriction on what you may build — it is what keeps the original
name falsifiable.**

The code is yours to take. The claim to have run *this* method is not.
